# Error Log — Frontend

> Lưu lỗi đã gặp và cách fix. Claude sẽ tham chiếu file này trước khi debug.

---

## Format

```
### [ERR-FE-001] Tên lỗi
- **Ngày:** YYYY-MM-DD
- **Môi trường:** local / staging / production
- **Mô tả lỗi:** Error message hoặc triệu chứng
- **Root cause:** Nguyên nhân gốc rễ
- **Cách fix:** Các bước giải quyết
- **Phòng tránh:** Làm gì để không tái phát?
```
